個人股票管理系統
一、專案介紹
本專案是一套使用 Python 開發的個人股票管理系統，
主要用來管理台股與美股資料、交易紀錄及每日投資筆記。
目前使用 SQLite 作為資料庫，並提供 CSV 匯出功能，
方便使用者整理及備份資料。
二、目前已完成的功能
股票資料新增、查詢與刪除
股票交易紀錄新增與查詢
每日投資筆記新增與查詢
SQLite 資料庫管理
股票、交易及筆記資料匯出 CSV
三、專案檔案架構
database.py：資料庫連線與初始化
stocks.py：股票資料管理
trades.py：交易紀錄管理
notes.py：每日筆記管理
export.py：CSV 匯出功能
main.py：主程式與功能整合
.gitignore：設定 Git 忽略的檔案
