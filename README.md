# 個人股票管理系統（Personal Stock Manager）

## 一、專案簡介

這是一個使用 Python 開發的個人股票管理系統，目標是整合台股與美股的追蹤、交易紀錄及每日筆記，方便管理投資資訊。

## 二、目前已完成的功能

- 新增及查看股票資料
- 新增及查看股票交易紀錄
- 新增及查看每日筆記
- 使用 SQLite 儲存資料
- 支援 CSV 資料匯出
- 使用 Google Colab 執行 Python 程式
- 將程式碼保存於 GitHub

## 三、開發工具

- Python
- Google Colab
- SQLite
- Pandas
- GitHub

## 五、注意事項

目前系統仍在開發階段，部分功能尚未完成。Google Colab 的執行環境可能重設，因此應定期備份 SQLite 資料庫。

資料庫可能包含個人投資紀錄，請勿上傳至公開的 GitHub 專案。

本專案目前以學習、測試及個人投資紀錄管理為主要目的。
